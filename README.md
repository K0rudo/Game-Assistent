# Ассистент для подбора видеоигр

Интеллектуальный ассистент, который собирает профиль игрока (характеристики ПК и игровые предпочтения) в диалоговом режиме, а затем подбирает подходящие игры с помощью RAG-подхода на основе OWL-онтологии и LLM (Perplexity API).

## Возможности

- **Диалоговый сбор профиля** — ассистент последовательно собирает 7 параметров: видеокарта (GPU), процессор (CPU), объём ОЗУ (RAM), жанр, поджанр, режим игры и возрастной рейтинг.
- **Строгая валидация** через JSON Schema (`response_format` в Perplexity API) — модель не может вернуть ответ вне заданной структуры.
- **Семантический поиск (RAG)** — на основе OWL-онтологии игр и эмбеддингов модели `sergeyzh/BERTA`.
- **LLM-ранжирование** — Perplexity `sonar` сортирует кандидатов с учётом характеристик ПК и предпочтений пользователя.
- **Интеграция со Steam** — подтягивает цену, скидку, отзывы и ссылку на страницу игры.
- **Интерактивный просмотр результатов** — навигация по играм, просмотр отзывов.

## Как это работает

Ассистент состоит из четырёх модулей, которые работают последовательно. Сначала `dialog_bot.py` ведёт диалог с пользователем и собирает профиль, сохраняя его в JSON. Затем `rag_engine.py` загружает OWL-онтологию, строит векторный индекс FAISS, находит top-N кандидатов и отправляет их в LLM для финального ранжирования. Далее `games_ui.py` парсит JSON-ответ от LLM, обогащает данные информацией со Steam и показывает карточки игр в консоли. Точка входа — `Assistent.py`, который связывает все модули вместе.
